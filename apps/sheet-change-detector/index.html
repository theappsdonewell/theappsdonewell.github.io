Sheet Change Detector

Find what changed. Not just what’s there.

A value changed.
So did a formula.

A familiar budget can look almost the same after an edit. In this sample, one value increased and a formula’s range grew by a row. Checking the numbers alone could miss the second change.

Compare two ranges in Google Sheets, or compare a saved snapshot with the current range. Review changes to values and formulas, cell by cell.

The extension is not publicly listed yet. Installation stays inactive until the official store link is verified.

From two versions
to a change list.

Work in Google Sheets with the Chrome extension. The sample above illustrates the result; it does not run a comparison on this website.

  1. Choose what to compare

    Select two sheet ranges, or use a saved snapshot as the earlier version of a range.

  2. Set up the match

    Compare by position, or match rows using a key column. Map columns when the two ranges are arranged differently.

  3. Review the differences

    Read the changed values and formulas in the change list. Check the before and after values before deciding what to do next.

What Pro adds.

Ten capabilities for matching less tidy data, taking results further and repeating a comparison. Free keeps the change list, with the limits above.

Highlight changes in source sheets
Pro applies highlights to the source sheets. Clearing highlights is also supported on Free.
Export the diff as CSV
Pro exports the comparison differences as a CSV file.
Merge review: apply approved changes
Pro applies approved changes. Free also includes the review list and approve/reject controls.
Fuzzy key matching
Pro matches similar keys using a similarity threshold you set.
Number tolerances
Pro supports absolute and percent tolerances for numeric comparisons.
Composite keys
Pro uses multiple columns together as the key for matching rows.
Saved presets
Pro creates, saves and applies comparison presets. Free can list and delete existing presets.
Comparison history
Pro records and re-opens comparisons. Free can read and delete existing history entries.
Scheduled comparisons
Pro creates and edits scheduled comparisons. Existing schedules pause on Free.
Side-by-side rows view
Pro shows rows side by side. Free retains the change list.
